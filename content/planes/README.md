# Plany i settingi

Strona rejestrowa planu/settingu (np. `srodziemie.md`) powstaje razem z
pierwszą materializowaną kartą z danego planu. Frontmatter: `typ: plan`,
`typIP` (`plan-mtg` / `zewnetrzne` / `custom`), opcjonalnie `mapa`
(slug = plan po utworzeniu mapy albo `pending`).

Proces mapowy: `docs/guides/PROCES_MAP.md` (ADR 0007).

Ten plik (README.md) nie jest stroną bazy — loader go pomija.
