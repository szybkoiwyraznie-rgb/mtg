# Karty Haseł

Encje świata wspólne dla wielu kart: geografia, fauna, frakcje, postacie,
wydarzenia, magia, artefakty, koncepcje (pełna klasyfikacja:
`docs/guides/SZKIELET_HASLA.md`). Nazwa pliku = slug encji
(np. `crebain.md`).

Hasła powstają link-miningiem (Pętla Jakości, ADR 0006) albo ze zlecenia
właściciela — nie „na zapas".

Ten plik (README.md) nie jest stroną bazy — loader go pomija.
