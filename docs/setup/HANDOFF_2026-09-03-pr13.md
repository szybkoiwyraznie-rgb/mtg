## Pułapki / obserwacje tej sesji

- **JSON i polskie cudzysłowy:** w `map.json` pinezka miała ASCII `"`
  wewnątrz wartości → parse error w teście MA2; w JSON używać wyłącznie
  „polskich" cudzysłowów albo ‚pojedynczych’. Test 46 (struktura
  map.json) wyłapuje to natychmiast.
- **ui-smoke licznik kart jest twardy** (`Karty Katalogowe (N)`) —
  przy każdej nowej karcie aktualizować linię testu.
- **Dedupe krawędzi dzielnic:** dwa sąsiednie poligony dzielą polilinię
  granicy; rysowanie obu daje ciemny „podwójny sztab". Renderer (T4)
  dedupe'uje po kluczu posortowanej pary wierzchołków —
  `granicaDzielnicy` rysuje się z `{zamkniete:false}`.
- **Etykiety punktowe vs obszarowe:** mover etykiet traktuje `x,y` inaczej
  dla etykiet małych (kandydat POD kotwicą) i `duze:true` (pozycja
  dokładna) — patrz pamięć sesji/PROJECT_HISTORY.
- **Raster QA:** sharp działa z `/tmp/qa-sharp` (npm prebuilt);
  crop density 150 → raster ~2500 px szerokości, `extract` w pikselach
  rastra (nie SVG). Pełny raster: density 96 + resize(1600).
- Ciemny obrys na zewnętrznym rimie dzielnic = **celowy shore-glow**
  atlasu (stroke lądu 3.5 + poświata), nie błąd geometrii.
