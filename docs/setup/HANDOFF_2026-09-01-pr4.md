## Pułapki / obserwacje

- **Nie próbuj pushować zmian w `.github/workflows/`** — token bota ich
  nie przepchnie (ENVIRONMENT §3); zmiany workflowów projektuje się
  w docs, wykonuje właściciel.
- `gh run rerun` potrafi odmówić („workflow file may be broken") mimo
  poprawnego pliku; naturalnym triggerem deployu jest push/scalenie do main.
- Sprawdzenie Pages API: `gh api repos/szybkoiwyraznie-rgb/mtg/pages`
  (404 = site nie istnieje; patrz L6).
- Sandbox resetuje workspace także **w środku** sesji — od razu
  `git fetch origin <gałąź> && git reset --hard FETCH_HEAD` (§2).
