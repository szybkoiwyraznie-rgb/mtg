## Pułapki / obserwacje

- `tools/wiki-stats.mjs` to raport informacyjny (bez progów); wzór
  w PETLA_JAKOSCI. Plany mierzone pragmatycznie („Setting w pigułce"),
  bo nie mają kontraktu sekcji w SZKIELET_*.
- Podczas edycji treści lore sprawdzaj `npm run stats` + `npm run build`,
  żeby nie podnieść martwego wikilinku (build pęka — ADR 0005).
- Handoff sprzed tej sesji (`HANDOFF_2026-08-31.md`) opisuje stan PR-2
  „w toku" — zastąpić w czytaniu tym plikiem.
- **Wzbogacanie mapy:** silnik renderuje podkład jako statyczny `<img>`
  (SVG base64); nowe elementy wizualne idą do `podklad.svg`, a nie do
  `map.json` (tam tylko pinezki/regiony/kotwice). Pinezki i `kotwice`
  używają współrzędnych znormalizowanych 0–1 (MA2) — zmiana wymiarów
  podkładu wymaga przeliczenia.
