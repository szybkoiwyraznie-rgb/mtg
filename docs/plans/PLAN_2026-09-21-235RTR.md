# Plan materializacji — 235RTR Trestle Troll

## Dostawa

- `imgId`: `235RTR`
- nazwa: `Trestle Troll`
- wydanie: `RTR` / Return to Ravnica
- plan: Ravnica

Zachować opis właściciela verbatim w `collection/entries/235rtr-trestle-troll.md`.

## Zakres

1. Pobrać i zapisać snapshot Scryfall dla RTR #205, oddzielając `imgId`
   właściciela od numeru kolekcjonerskiego.
2. Zredagować Kartę Katalogową LORE-first: troll jako żywa zapora estakady,
   Golgari, wilgotna geografia podziemnej Ravnicy, cytowanie dostawy i
   snapshotu; mechanikę opisać dopiero w końcowej sekcji.
3. Dodać regionalną pinezkę karty na mapie Ravnicy przy podziemnym rejonie
   Golgari / Korozda lub Svogthos, bez wymyślania konkretnego mostu.
4. Dodać regresję dla wpisu, snapshotu, karty, mechaniki i pinezki.
5. Wykonać `npm test`, `npm run build`, `python3 tools/map-audit.py` i
   `node tools/wiki-stats.mjs`; zaktualizować dokumentację dopiero po
   ostatnim commicie produktu.

## Granice

- Nie tworzyć nowego hasła dla Trestle Trolla ani estakady: próg dwóch kart
  nie jest spełniony.
- Nie generować grafik. Nie naruszać istniejących wpisów kolekcji.
- Nazwa, Oracle, flavor, set i numer pochodzą ze snapshotu Scryfall;
  opis świata wynika z dostawy i cytowanych źródeł.
