# Plan materializacji — 9WAR Toll of the Invasion

## Dostawa

- **imgId właściciela:** `9WAR`
- **Nazwa:** `Toll of the Invasion`
- **Wydanie:** `WAR` / War of the Spark
- **Plan docelowy:** `Ravnica`
- **Treść właściciela:** zachować verbatim w `collection/entries/9war-toll-of-the-invasion.md`.

## Kanon karty — snapshot Scryfall

Źródło nadrzędne: <https://api.scryfall.com/cards/named?exact=Toll%20of%20the%20Invasion&set=war>.

Scryfall zwrócił WAR #108: koszt `{2}{B}`, `Sorcery`, common, artysta Joe Slucher.
Mechanika: przeciwnik ujawnia rękę, wybierana jest nielądowa karta do odrzucenia,
a następnie karta tworzy lub wzmacnia Armię Zombie przez `Amass Zombies 1`.
Snapshot nie ma `flavor_text`; nie dopisywać oficjalnego flavoru.

Pełny wynik API zostanie zapisany bez ręcznego skracania w
`scryfall/9war-toll-of-the-invasion.json`, z notką rozdzielającą prywatne
`imgId: 9WAR` od `collector_number: 108`.

## Karta Katalogowa

Utworzyć `content/cards/9war-toll-of-the-invasion.md` jako kartę LORE-first.
Scena zachowa narrację właściciela: zwykły cywil na zniszczonej ulicy Ravnicy,
wyrwane wspomnienie zabierane przez mglistą dłoń, nowo powołany lazotepowy
Wieczny oraz cytadela Nicola Bolasa nad miastem.

Mechanika pozostanie zgodna ze snapshotem i zostanie opowiedziana dopiero
w sekcji mechaniki: kradzież wybranej myśli jako ujawnienie i odrzucenie
nielądowej karty, a Wieczny jako `Amass Zombies 1`. Brak oficjalnego flavoru
zostanie oznaczony jawnie, bez tworzenia inskrypcji.

## Mapa

Dodać kartową pinezkę `9war-toll-of-the-invasion` do
`maps/ravnica/map.json` jako `pewnosc: region`, przy istniejącej regionalnej
kotwicy Ravnicy/Dziesiątego Dystryktu. Nie wskazywać konkretnej ulicy,
cywilnego domu ani lokalizacji cytadeli, ponieważ dostawa opisuje szeroką
scenę wojny, nie nazwany punkt mapy. Nie przesuwać istniejących pinezek.

## Regresja i bramki

Utworzyć `test/ravnica-9war.test.js`, pilnujący wpisu verbatim, rozdziału
`imgId`/numeru kolekcjonerskiego, snapshotu, mechaniki, braku flavoru,
LORE-first, regionalnej pinezki i braku nowego hasła poniżej progu.

Po produkcie uruchomić:

- `node --test test/ravnica-9war.test.js`
- `npm test`
- `npm run build`
- `python3 tools/map-audit.py`
- `node tools/wiki-stats.mjs`
- `git diff --check`

Dokumentację historii, roadmapy, aktualności i handoffu aktualizować dopiero
po ostatnim commicie produktu; nie generować grafik.
